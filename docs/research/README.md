# Engineering Records

This folder contains repository-level records that support the manual's requirement for engineering evidence and traceability in the **system repository**.

Use these files to summarize work that is better maintained near the codebase, including:

* backlog and MVP scope references
* testing and validation evidence
* CI/CD and quality gate notes
* sprint and release traceability

Formal appendix records for gate evaluations, retrospectives, and review-planning documents still belong in the documentation repository unless your instructor explicitly directs otherwise.
